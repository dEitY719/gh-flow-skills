Step 1 목적지 해석에서 정지
$ git remote -v

upstream 이 없고 명시적 --remote 도 없으므로 계약대로 하드 에러로 정지했다 — origin 폴백은 일어나지 않는다. Step 2 의 push 가능성 프로브에는 도달하지 않았다.

Step 2 프로브는 실제 throwaway ref 를 목적지에 push 하고, Step 5~6 은 gist 를 만들고 목적지 이슈에 코멘트를 단다. 모두 외부 쓰기이므로 이 문서 범위 밖이다.
